# 可調欄位見 KmCosConfig.DEFAULTS，常用：
#   target_system / target_system_file  要誘發的人格

#   seeds        中性題種子（預設 pipelines/data/km_cos_prompts.jsonl）
#   sign         both | positive | negative
#   start_k / end_m   留 0 由保守界派生；指定則固定範圍
#   control_repeats   隨機對照次數
